## 🛠️ Setup Instructions

If you'd like to use this template or preview it on your local machine, follow these steps:

### Prerequisites
- Any modern web browser (Chrome, Edge, Firefox, Safari).
- *(Optional)* [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) if you are using VS Code for auto-reloading.

### Installation Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Virang007/Portfolio.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd Portfolio
   ```

3. **Run the application:**
   - **Method 1:** Double-click the `index.html` file to open it directly in your default browser.
   - **Method 2:** Open the project folder in VS Code and click the "Go Live" button at the bottom right corner (if you have Live Server installed).
   - **Method 3:** Using Python (if installed):
     ```bash
     python -m http.server 8000
     ```
     Then open `http://localhost:8000` in your web browser.

## 🚀 Deployment Options

**1. GitHub Pages (Free)**
- Create a GitHub repository and upload your files.
- Enable GitHub Pages in repository settings.
- Your site will be available at `username.github.io/repository-name`.

**2. Netlify (Free)**
- Drag and drop your folder to Netlify.
- Get instant deployment with custom domain option.
- Automatic updates on file changes.

**3. Vercel (Free)**
- Connect your GitHub repository.
- Automatic deployment on push.
- Great performance and analytics.

**4. Traditional Hosting**
- Upload files to any web hosting service via FTP/cPanel.

## 🐛 Troubleshooting

**Common Issues:**
- **Fonts not loading**: Check internet connection (Google Fonts).
- **Icons not showing**: Verify Font Awesome CDN is accessible.
- **Mobile menu not working**: Check JavaScript console for errors.
- **Styling issues**: Clear browser cache and reload.
